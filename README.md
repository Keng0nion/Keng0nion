## Selected work

### [Ecolab](https://github.com/Keng0nion/ecolab-antibiotic-modeling)

A bilingual, local-first computational-biology and applied-mathematics workspace for *E. coli* population modeling, interactive learning, and reproducible real-data evaluation.

- Implements a versioned population-dynamics model with explicit units, provenance, and scientific limitations.
- Uses a public BW25113 OD600 dataset with quality control, complete-trajectory training/validation separation, parameter fitting, Monte Carlo analysis, and local, Morris, and Sobol–Jansen sensitivity analysis.
- Preserves a negative result: the fitted model underperformed a predeclared simple baseline on held-out data.
- Runs entirely in the browser and includes an automated test suite and reproducible release workflow.

### [Collatz Reverse Tree Interactive Visualizer](https://github.com/Keng0nion/Collatz-Conjecture-Reverse-Tree-Interactive-Visualizer)

An interactive mathematics tool for exploring cycle-pruned reverse Collatz trees, forward trajectories, and two coordinate representations. It supports adjustable depth, trajectory highlighting, and high-resolution graph export.

## Current direction

I am building stronger foundations in calculus, linear algebra, probability, statistics, algorithms, and molecular biology. My long-term goal is to study how mathematical and computational methods can be used responsibly in biological research.

## Principles

- Keep data provenance and model assumptions visible.
- Separate training, validation, and interpretation.
- Prefer reproducible evidence over impressive claims.
- Treat negative results as information rather than something to hide.
